# Hands-On: Employee Management System Using Spring MVC + Hibernate (Java Configuration)

## Objective

Develop a web-based Employee Management System using **Spring MVC**, **Hibernate**, and **Oracle/MySQL Database** with **pure Java Configuration (No XML)**.

The application should allow users to:

* Add a new employee
* View all employees
* Search employee by ID
* Update employee details
* Delete employee records

---

# Problem Statement

ABC Technologies wants to digitize its employee management process. The company requires a web application where HR personnel can maintain employee information.

You have been assigned to develop the application using:

* Spring MVC
* Hibernate ORM
* Java-Based Configuration
* JSP Views
* Oracle/MySQL Database

The application must follow the MVC architecture and use Hibernate for database operations.

---

# Functional Requirements

## Module 1: Employee Entity

Create an entity class named `Employee`.

### Attributes

| Field        | Type    |
| ------------ | ------- |
| employeeId   | Integer |
| employeeName | String  |
| department   | String  |
| salary       | Double  |
| email        | String  |

### Requirements

* Map the class using Hibernate annotations.
* Configure `employeeId` as the primary key.

---

## Module 2: DAO Layer

Create:  
EmployeeDAO
 

### Methods

 
void saveEmployee(Employee employee);

List<Employee> getAllEmployees();

Employee findEmployeeById(int employeeId);

void updateEmployee(Employee employee);

void deleteEmployee(int employeeId);
 

---

## Module 3: Service Layer

Create:

 
EmployeeService
 

### Responsibilities

* Interact with DAO layer
* Manage business operations
* Handle transactions

---

## Module 4: Controller Layer

Create:

 
EmployeeController
 

### Request Mappings

| URL                   | Description           |
| --------------------- | --------------------- |
| /employee/register    | Display Employee Form |
| /employee/save        | Save Employee         |
| /employee/list        | Display All Employees |
| /employee/edit/{id}   | Edit Employee         |
| /employee/delete/{id} | Delete Employee       |

# Java Configuration Requirements

## 1. Web Initializer

Create:

 
public class WebAppInitializer
       extends AbstractAnnotationConfigDispatcherServletInitializer
```

Responsibilities:

* Register DispatcherServlet
* Load configuration classes

---

## 2. Spring MVC Configuration

Create:

 
@Configuration
@EnableWebMvc
@ComponentScan("com.company")
public class WebConfig
 

Configure:

* ViewResolver
* Component Scanning

---

## 3. Hibernate Configuration

Create:

 
@Configuration
@EnableTransactionManagement
public class HibernateConfig
 

Configure:

* DataSource
* SessionFactory
* Hibernate Properties
* Transaction Manager
