# Hands-On: Employee Management REST API with Spring Security (Basic Authentication)

## Objective

Develop a secure Employee Management REST API using **Spring Boot**, **Spring Security**, and **MySQL/Oracle**.

The application should:

* Authenticate users using Spring Security.
* Authorize users based on roles (**ADMIN** and **USER**).
* Secure REST endpoints.
* Implement Custom Exceptions and Global Exception Handling.
* Store employee data in the database.

---

# Problem Statement

XYZ Technologies wants to secure its Employee Management APIs. Only authenticated users should be allowed to access the APIs, and certain operations should be restricted based on user roles.

Develop a Spring Boot REST application that:

* Allows authenticated users to view employee information.
* Allows only administrators to create, update, and delete employees.
* Returns proper error responses for unauthorized and forbidden access.

# Custom Exceptions

## EmployeeNotFoundException

Throw when:

```text
Employee ID does not exist.
```

Example:

```java

    "Employee with ID " + id + " not found"
);
```

# Global Exception Handler

Create:

```java
@RestControllerAdvice
public class GlobalExceptionHandler
```

Handle:

### EmployeeNotFoundException

```json
{
  "status": 404,
  "message": "Employee with ID 101 not found"
}
```

---

### AccessDeniedException

```json
{
  "status": 403,
  "message": "Access Denied. You do not have permission."
}
```

---

### AuthenticationException

```json
{
  "status": 401,
  "message": "Invalid Username or Password"
}
```

# Challenge Extension (JWT Security)

After completing Basic Authentication, upgrade the application to use **JWT Authentication**:

### Additional APIs

```http
POST /auth/login
```

Request:

```json
{
  "username": "admin",
  "password": "admin123"
}
```

Response:

```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9..."
}
```

Then secure all Employee APIs using JWT tokens instead of Basic Authentication. This extension introduces:

* JWT Generation
* JWT Validation
* Custom Authentication Filter
* Stateless Session Management.
