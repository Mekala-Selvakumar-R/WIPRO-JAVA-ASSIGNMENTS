# Hands-On: Secure Product Management REST API Using Spring Security + JWT

## Objective

Develop a RESTful Product Management System using:

* Spring Boot
* Spring Security
* JWT (JSON Web Token)
* Spring Data JPA
* MySQL / Oracle Database
* Custom Exceptions
* Global Exception Handling

The application should authenticate users using JWT and authorize access based on roles.

---

# Problem Statement

ABC Retail wants to expose Product Management APIs to its mobile and web applications. Since the APIs contain sensitive business information, only authenticated users should be able to access them.

Develop a secure REST API that:

* Authenticates users using username and password.
* Generates JWT tokens upon successful login.
* Allows users to access APIs using JWT tokens.
* Restricts certain operations to ADMIN users only.
* Handles authentication and authorization failures gracefully.

# JWT Requirements

Create a utility class:

```java
JwtUtil
```

Responsibilities:

* Generate JWT Token
* Validate JWT Token
* Extract Username from Token
* Check Token Expiration

Methods:

```java
String generateToken(String username);

String extractUsername(String token);

boolean validateToken(String token);
```

---

# Security Configuration

Create:

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig
```

Requirements:

* Disable CSRF
* Stateless Session Management
* Configure JWT Filter
* Configure Authentication Provider
* Configure BCryptPasswordEncoder

---

# JWT Filter

Create:

```java
JwtAuthenticationFilter
```

Responsibilities:

* Read Authorization Header
* Extract JWT Token
* Validate Token
* Authenticate User

Expected Header:

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
```

# Custom Exceptions

## ProductNotFoundException

Throw when:

```text
Requested Product ID is not available.
```

Example:

```java
throw new ProductNotFoundException(
      "Product with ID " + id + " not found");
```

---

## InvalidTokenException

Throw when:

```text
JWT token is invalid or expired.
```

---

# Global Exception Handler

Create:

```java
@RestControllerAdvice
public class GlobalExceptionHandler
```

Handle:

### ProductNotFoundException

```json
{
  "status": 404,
  "message": "Product with ID 101 not found"
}
```

---

### InvalidTokenException

```json
{
  "status": 401,
  "message": "Invalid or Expired Token"
}
```

---

### AccessDeniedException

```json
{
  "status": 403,
  "message": "Access Denied"
}
```

---

### MethodArgumentNotValidException

```json
{
  "productName": "Product Name is required",
  "price": "Price must be greater than zero"
}
```
